# FG Remote 1.0.0

ريموت مستقل للتكييفات والمراوح من FG Machines، مع استمرار الريموت داخل FG Link.

- حزمة مستقلة `com.fgmachines.remote`، تُثبّت بجانب FG Link.
- أيقونة مميزة بخلفية داكنة وإطار فضي وموجات زرقاء وأزرار خضراء.
- العربية RTL، الإنجليزية، التركية، الإسبانية والألمانية.
- صفحة المطور من FG Link: الشعار والموقع والبريد والحساب الشخصي والصفحة التجارية.
- نفس بروتوكولات الأشعة تحت الحمراء ومعالج فحص الاستجابة الموجودين في FG Link.
- إعدادات مستقلة دون حساب أو خادم.

نجحت اختبارات البروتوكولات وفحص البناء وواجهة المحاكي. الإرسال الفعلي للأشعة تحت الحمراء يحتاج هاتفًا بمرسل IR وجهازًا متوافقًا؛ لم يُختبر على جهاز فعلي ضمن هذا الإصدار.
